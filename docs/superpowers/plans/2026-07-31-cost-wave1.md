# Cost Wave 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement spec v3 (`docs/superpowers/specs/2026-07-31-cost-wave1-harness-caching-trims-design.md`): the cost-assertion harness (instrumentation, runner, manifest, S-1 WS driver), the ai.ts cache-blocks seam, and ST/gate/tripwire prompt caching — every saving proven by wire-level dollar assertions.

**Architecture:** Instrumentation + harness lib + blocks seam + WS driver land in parallel (disjoint); the runner assembles them and pins baselines; caching lands only after baselines exist so every delta is proven; weekly ECS wiring last. The spec is NORMATIVE for every mechanism (USD derivation, TTL clock, 4096 minimums, decision-parity gate).

**Tech Stack:** pino NDJSON capture, existing model-pricing table, ai@6 blocks compilation to per-message cacheControl, BullMQ-quiescence windowing, WS (ws-transport plumbing), Terraform (EventBridge + ECS run-task).

## Global Constraints

- Spec v3 is NORMATIVE — USD derivation (base = inputTokens − cacheRead − cacheWrite; 1.25× writes; 0.1× reads), drained-queue quiescence, per-model+TTL-aware assertions, 4096-span conditionals (logged-not-failed), scenario-MEAN bands, dollars seeded from first verified runs (never §2's intro-priced numbers), 3–5 baselines before bands pin.
- `providerOptions.mythrun` rides the existing `stage` string shape — do not fork the context type.
- The blocks compiler asserts ≤4 breakpoints; call-level cacheControl is WRONG-PLACEMENT auto-caching, never a shortcut; §2 tests assert the blocks path.
- Cache-first ordering is law: NO prompt-content trims in this wave; template REORDERS only, stable-first, with the tripwire's decision-parity gate mandatory.
- Enforced ignorance untouched; ZFC untouched (all mechanism, no cognition).
- Real-Anthropic runs: on-demand only from the runner; never wired into pre-push/CI. Budget ~$2–4 per full suite run; baselines ≤ $20 total.
- Standing process: TDD; implementers run scoped tests only, never commit; controller commits serially; 100% backend coverage gate.
- Waves: W1 = T1 ∥ T2 ∥ T3 ∥ T4 (disjoint); W2 = T5; W3 = T6 ∥ T7 (disjoint templates/call sites); W4 = T8 ∥ T9(controller).
