Network

The VPC everything else runs in. Two AZs, public/private split, a single NAT, and four security groups that carve out who can talk to whom.

How it fits together

The VPC (10.0.0.0/16) spans two availability zones in us-east-1. Each AZ has one public and one private subnet. Public subnets hold the ALB and the NAT Gateway. Private subnets hold ECS tasks, RDS, and Redis — nothing in them has a public IP, and map_public_ip_on_launch is off even in the public subnets.

Two AZs, not three — RDS needs a DB subnet group spanning at least two AZs even for Single-AZ instances. Three AZs at launch would add a third NAT-gateway-sized cost without changing availability for anything we're running today. The module accepts a list and can be bumped to three without a rewrite.
Single NAT (not an HA pair) — a per-AZ NAT pair would double the ~$32/month NAT cost. A shared route table points both private subnets at the NAT in AZ-a. The num_nat_gateways variable exists so the module splits into per-AZ route tables the day AZ-a outage tolerance matters.

Security groups

Four SGs carve out traffic paths, each with ingress and egress declared as separate resources:

  • alb — inbound 443 from the internet; egress to anywhere.
  • ecs — inbound 3000 from the ALB SG; egress to 443 on the internet, 5432 to RDS, 6379 to Redis.
  • rds — inbound 5432 from the ECS SG; no egress.
  • redis — inbound 6379 from the ECS SG; no egress.
No default egress on SGs — Terraform's aws_security_group now creates groups with no egress rules unless you add them, and all four SGs declare egress explicitly. RDS and Redis have no egress at all: they have no legitimate outbound need, and the deny is a cheap defense-in-depth layer if something is ever accidentally launched into the wrong group.

The VPC's default SG is also zeroed out with an empty aws_default_security_group resource. Anything accidentally launched without an explicit SG inherits zero rules.

Routing

The public route table sends 0.0.0.0/0 through the Internet Gateway; both public subnets attach to it. The private route table sends 0.0.0.0/0 through the NAT Gateway; both private subnets attach to it. The NAT's Elastic IP is the only public IP in the VPC that Mythrun owns.

Integration points

The Data module places RDS and Redis into the private subnets and attaches them to the rds and redis SGs. The Serving module places ECS tasks into the private subnets under the ecs SG, and the shared ALB lives in the public subnets under the alb SG.
