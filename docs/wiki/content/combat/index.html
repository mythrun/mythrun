Combat

Rules engine, voxel maps, map rendering.

The first slice is built: Single-shot combat (L1) activates the exploration↔combat session mode and a single-shot resolver — a fight resolves in one beat (the dice decide the outcome, the Fast Thinker narrates it), the shared character ledger updates, and any party member resumes. It is the placeholder the round-by-round combat mode (turns, enemy stat blocks, the action stack, voxel maps) grows into.
