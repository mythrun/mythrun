Reference

Derived views over the shipped system. For looking up specific things, not for learning how the system fits together — the topical sections (Infra, Runtime, Data, Auth & Billing, World & Campaign, Combat, Frontend) are where the system is explained.

Reference pages are auto-generated. The runbook index aggregates every runbook entry across the narrative pages; the schema reference is regenerated from backend/migrations/ on every wiki build. They go stale only if the upstream source changes and the generator hasn't been rerun — the source-hash drift check catches that case in CI.
