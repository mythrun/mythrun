Mythrun Wiki

An agent-maintained, as-built view of the whole Mythrun system — both the application code and the AWS infrastructure. Diagrammed, cross-linked, and updated alongside every Linear issue that ships.

Sections

The wiki is organized into seven sections. Infra comes first because AWS resources are inherently harder to hold in your head than code; visualizing them cleanly is the highest-leverage payoff.

  • Infra — AWS topology, Terraform modules, environments, networking, compute, data plane, DNS, secrets, CI/CD, observability.
  • Runtime — the backend server, session loop, Fast Thinker, Slow Thinker, Scribe, DM Trigger, prompts, Anthropic integration.
  • Data — schemas, repositories, Postgres, Redis, BullMQ.
  • Auth & Billing — Cognito, JWT, invites, Stripe, credits.
  • World & Campaign — prep engine, world store, campaign pipeline.
  • Combat — rules engine, voxel maps, map rendering.
  • Frontend — components, Three.js layer, design system adapters.

How this is maintained

Every section page declares which source files (code paths, Terraform directories) it documents. On each build, the wiki computes a hash of those sources and compares it to the hash captured at the page's last update. Mismatches render a visible drift banner on the page and fail pnpm wiki:check in CI, so pages can't silently go stale.
